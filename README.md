# Contact Management System in C

## About the Project
The Contact Management System is a simple console-based application developed using the C programming language. It allows users to manage their contacts by storing, viewing, searching, updating, and deleting contact information.

## Features
- Add new contacts
- View all saved contacts
- Search contacts by name
- Update contact details
- Delete contacts
- Store contact information such as name, phone number, and email address
- Simple menu-driven interface

## Technologies Used
- C Programming Language
- Standard C Libraries

## How to Run
1. Clone or download this repository.
2. Open the source code in a C compiler.
3. Compile the program.
4. Run the executable file.
5. Select the desired option from the menu.

## Sample Menu

```text
===== Contact Management System =====

1. Add Contact

5. Delete Contact
6. Exit

Enter your choice:
```
